# Fair-Taley

這個 repo 的 main（GitHub Pages）拿來做 AI 驅動的自由文字遊戲：預設手動複製提示詞給 AI，不一定要接 API。目前在設計討論階段，見 `設計文件/核心設計.md`。

## 檔案
- `設計文件/核心設計.md` — 新專案已拍板的設計（檔尾「討論中」是還沒定的）。
- `設計文件/點子庫.txt` — 想到但還沒用上的點子，都還沒拍板。
- `封存_童話/` — 已封存的遊戲「童話？」（設計文件、更新日誌、要求清單），原封不動收在這裡。完整備份另存在分支 `archive/fairy-tale`。
- `更新日誌.txt` — 每次更新做了什麼（最新在最上面）。
- `納可要求清單.txt` — 待辦與已完成清單。
- `CLAUDE.md` — 給協作的 Claude 的工作規則。
