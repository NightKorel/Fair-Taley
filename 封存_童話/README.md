# 童話？

一群角色被強迫參加一場遊戲，**要一齣齣把童話故事演成功才能離開**。
但童話通常都會死人——照原劇本演，你的人就得死。你不是下場的演員，你是**坐鎮指派的人**：
把手上的角色派進童話裡有限的幾個位置，想辦法把戲演「成立」、又不讓自己的人死。

> 目前處於藍圖討論階段，還沒有遊戲程式。核心設計見 `設計文件/核心設計.md`。

## 檔案
- `設計文件/` — 設計筆記（核心設計、之後的關卡/角色/世界觀）。
- `更新日誌.txt` — 每次更新做了什麼（最新在最上面）。
- `納可要求清單.txt` — 待辦與已完成清單。
- `CLAUDE.md` — 給協作的 Claude 的工作規則。
